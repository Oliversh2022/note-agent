# 周报：学习记录与计划（前端基础与工程实践）

本周以“织见赣韵”和 ORBITAL 两个项目的开发经历反向驱动学习，重点补齐前端基础与工程实践，目标是从“能跑起来”提升到“能解释、能维护”。学习内容覆盖 JavaScript 异步、事件机制、模块化，TypeScript 类型约束，以及 React 状态管理与组件拆分；并通过两条全链路追踪方法、问题记录规范、工具实践和三条原则，将学习与面试复盘统一起来。

## 本周学习定位

学习不是泛泛过知识点，而是由已完成项目“织见赣韵”和 ORBITAL 的实际开发经历反向驱动：哪里写得不扎实就补哪里。当前核心任务是补齐前端基础与工程实践，把“能跑起来”提升到“能解释、能维护”。

## 知识重点

重点包括六项：1）JavaScript 异步处理：复习 Promise / async 相关异步流程控制；2）JavaScript 事件机制：理解事件触发、传递与响应；3）JavaScript 模块化：理解代码拆分与组织；4）TypeScript 类型约束：理解类型系统的约束作用，不把类型当注释写；5）React 状态管理：明确状态放在哪、怎么变、谁来消费；6）React 组件拆分：把握组件边界与复用。前三点归为前端基础，后三点对应 TS 与 React 工程能力。

## 学习方法：两条全链路追踪路径

路径 A：追踪一次用户操作如何更新状态、如何保存数据、如何恢复页面，覆盖 React 状态管理与持久化，对应面试题中刺绣作品保存与恢复所需的状态结构、本地存储、异常处理。路径 B：梳理一次 AI 请求如何经过服务端并流式返回，覆盖前后端协作与异步/流式处理，对应 ORBITAL 的 AI 解读逐步显示，包括前端请求、服务端调用、SSE 内容拼接。

## 问题记录规范

遇到问题按固定四要素记录，避免“解决了就忘”：1）现象：出了什么错、表现是什么；2）原因：根因是什么；3）修改：改了什么；4）验证结果：怎么确认修好了。

## 工具与实践练习

持续进行 Git 版本管理练习、接口调试练习和浏览器测试，在真实环境中验证行为，提升联调与工程实践能力。

## 三条原则与边界

1）文化资料准确性：文化资料保留来源，不丢出处；2）数字模拟诚实性：明确模拟边界，不把模拟说成事实；3）AI 生成代码使用方式：先理解再使用，逐步做到能独立解释和维护。第 3 条与面试题中“如何使用 AI 辅助开发”的要求一致，包括任务拆解、代码审查、验证过程，并清楚区分生成内容与自己的判断。

## 关联印证：面试题中的学习落点

本周学习重点正是面试要讲清的五件事：1）如何介绍“织见赣韵”，涉及项目叙事与文化资料溯源；2）为什么用 React、TypeScript、Vite，对应 TS 类型约束与 React 组件拆分；3）刺绣作品如何保存和恢复，对应方法路径 A；4）ORBITAL 的 AI 解读如何逐步显示，对应方法路径 B；5）如何使用 AI 辅助开发，对应原则第 3 条。学习与复盘是同一件事。

## 下周可执行清单

1）完成路径 A 追踪：从用户操作到状态更新、保存、页面恢复，全程能讲清；2）完成路径 B 追踪：AI 请求经服务端到流式返回的完整链路，含 SSE 拼接；3）整理本周问题记录至少若干条，包含现象、原因、修改、验证结果；4）能自圆其说 React + TS + Vite 的选型理由，包括组件复用、类型检查、构建体验；5）复习 JS 异步、事件机制、模块化三块基础题；6）继续 Git、接口调试、浏览器测试练习。
